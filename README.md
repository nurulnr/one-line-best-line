Entrants write a single line of at most 240 characters on any free and entertaining theme, and an AI judge pairs the lines up until the most scroll-stopping one takes the reward.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `entry.txt` in the output directory. The line is fixed text, 118 characters, so the output is byte-identical on every run and uses no network.
